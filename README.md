# 100-in-1-godot-games
Random games implemented in Godot

## Start the game from CLI

```bash
  /path/to/godot --path /path/to/your/project_folder/ res://scenes/main.tscn
```

Example on MacOs assuming you are in the project directory:
```bash
  /Applications/Godot.app/Contents/MacOS/Godot ./ res://scenes/menu/menu.tscn
```
